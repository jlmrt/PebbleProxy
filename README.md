# Pebble Proxy

> [!WARNING]
> Experimental pre-release software. It has not completed end-to-end testing on Umbrel and is not ready for production use. Keep the admin interface private, protect every public endpoint with a device token, and do not rely on this build for irreplaceable recordings or data.

Pebble Proxy is a self-hosted Umbrel gateway that connects compatible Pebble apps to private speech-to-text and OpenAI-compatible AI services. It provides per-device authentication, fixed model aliases, voice recording ingestion, and device-scoped notes and reminders while keeping backend credentials inside the Umbrel network.

Detailed installation, configuration, and security documentation will be published after the custom app-store package and complete workflow have been verified on real Umbrel hardware.
